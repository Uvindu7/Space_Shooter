Project Overview :

This project is a 2D game developed using Unity and C#. It demonstrates game development fundamentals, including player movement, gameplay mechanics, collision detection, and interaction with the game environment. The project uses Unity's game engine to manage scenes, game objects, and gameplay logic, providing an interactive gaming experience.

Features :

2D gameplay and player controls
Player movement and interaction
Collision detection and game physics
Game environment and scene management
C# scripts for gameplay logic
Interactive gaming experience

Technologies Used :

Unity
C#
Visual Studio Code
Unity Editor
